# Fake News Detection using LSTM

This project detects whether a news article is Real or Fake using an LSTM neural network.

## Technologies
- Python
- TensorFlow
- Keras
- Pandas
- NumPy
- Scikit-learn

## Accuracy
95.7%

## Files
- train.py
- predict.py
- news_model.keras
- tokenizer.pkl
- Fake.csv
- True.csv

- ## Dataset
- This project uses the Fake and Real News Dataset from Kaggle.

- Dataset Link:
- https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset
